AM CREATIVE WEBSITE

Files:
- index.html: website structure
- style.css: original cream/black/orange design, responsive layout
- script.js: 20 products, category filter, search, product details, cart, and WhatsApp order
- images/: put your own product photos here

HOW TO RUN:
1. Keep index.html, style.css, script.js, and images folder together.
2. Open index.html in a browser, or use Live Server in VS Code.
3. Replace WHATSAPP_NUMBER in script.js with your real WhatsApp number in international format (Sri Lanka example: 947XXXXXXXX, without + or spaces).
4. Add photos using the exact filenames used in script.js, for example images/mug-1.jpg and images/frame-1.jpg.

If a product photo is missing in the product card, an emoji placeholder appears. This is a front-end demo; cart data is not saved after the page is refreshed, and orders are sent by the customer through WhatsApp.
